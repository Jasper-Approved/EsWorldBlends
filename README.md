🌌 EsWorld Blends — Cosmic Front Page
A lightweight cosmic landing page for EsWorld Blends, the small batch espresso craftwork of Anchorage, Alaska.  This repository hosts the public GitHub Pages site that serves as the front door to the Square ordering lane.
✨ About
EsWorld Blends is a micro roastery and café identity built around cosmic themes, nebula aesthetics, and small batch espresso engineering.  This repo contains:
•	The cosmic landing page (index.html)
•	Blend gallery images
•	Starfield background assets
•	Redirect link to the official Square ordering site
The goal is to provide a clean, fast, cosmic themed front page that reflects the EsWorld identity while keeping ordering handled through Square.
🌠 Features
•	Cosmic nebula gradient background
•	Starfield overlay
•	Glow enhanced blend gallery
•	Aurora style “Order Now” button
•	Lightweight, GitHub Pages friendly HTML/CSS
•	No external libraries or dependencies
🚀 Deployment
This site is deployed using GitHub Pages.
Steps:
1.	Ensure the repository is public
2.	Add your index.html and image assets
3.	Go to Settings → Pages
4.	Set:
o	Source: Deploy from branch
o	Branch: main
o	Folder: /root
5.	GitHub will generate your public site URL
Your site will appear at:
Code
https://Jasper-Approved.github.io/EsWorldBlends/
